Политика конфиденциальности vlmb.ru

vlmb.ru — личная база знаний одного человека. Сайт закрыт: войти может только владелец.

Какие данные используются

При входе через GitHub сайт получает логин, имя и аватар, чтобы проверить, что это владелец. При подключении Google Tasks сайт получает доступ к спискам и задачам владельца в Google Tasks (область доступа https://www.googleapis.com/auth/tasks).

Зачем

Только чтобы показывать и редактировать задачи на сайте и синхронизировать их с заметками владельца в его личном репозитории GitHub. Данные не продаются, не передаются третьим лицам и не используются для рекламы или обучения моделей.

Где хранятся

Токены доступа хранятся на сервере сайта в зашифрованном виде. Задачи, синхронизированные с заметками, лежат в личном репозитории владельца на GitHub.

Как отозвать доступ

На сайте: «Настройки → Google Tasks → Отключить». Или в аккаунте Google: myaccount.google.com/permissions.
